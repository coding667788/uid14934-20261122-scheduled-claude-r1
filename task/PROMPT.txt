插件上线审批需要一个验证器。它读取自定义教学指令的程序，判断其是否能安全运行在只读档案沙箱。程序不实际加载或执行插件，不接触宿主文件。实现一套定义完整的离线验证器与解释器对照测试，围绕以下小语言展开。

每段程序包括标号、类型固定的寄存器及指令。允许常量、复制、带显式上下界的加减、有限区间分支、带最大迭代数的循环、调用声明的子函数、读取指定区间、记录公开结果。函数调用图无环，但同一函数可由多调用点共享。读取区间的权限由入口赋予的能力标签限制，受限于对象、偏移、幅度及访问模式。整数运算以输入规定的位宽做模运算。出界或类型错误会产生可观察的陷入事件。数据既有公开/机密标签，也有低置信/已认可标签。低置信的值必须经指定检查才能作为索引，认可只对该区间极性成立，寄存器重新赋值后不得沿用。依赖机密的分支把控制标签带到对应合流点；受其控制的公开输出和提前陷入均算违规，函数内部返回亦遵守调用方控制标签。程序允许按固定策略进行显式脱敏，但其许可只消除指定数据标签，不清除控制标签或索引置信要求。

验证器对整个合法输入集合证明每次读取、公开输出及可观察陷入满足条件。发现问题时对给定小语言输出最短的违规指令轨迹和一组合法输入，等长按指令序列、输入字典序取最小；无法在输入提供的分析预算内证明时返回未证明并首报导致不收敛的程序点，不得当作通过。解释器只执行合成样例用于独立对照。支持总计 120 条指令、6 层函数调用、单循环至多 64 次和 32 位值，不得枚举全部输入。实现分支约束、循环以及可复用的调用摘要，说明何时可合并控制状态；覆盖模回绕使区间条件失效、外层机密分支通过子函数输出、循环中认可被更新覆盖、区间边界重合、以及相同参数在不同控制上下文的结果不同。小位宽时验证器与独立解释器逐输入对拍。

交付的 Windows 原生 Python 3.12 仓库从零搭建。只使用标准库、CPU 和人工合成指令。main 入口为 python -m vm_verify CASE.json，返回 UTF-8 JSON，结构非法要定位到函数、指令和字段。README 给出语言及报告完备定义，附可运行样例与可由 unittest 执行的标准库测试。
